> Part of my networking study series. These are my personal notes, rewritten in plain English so they actually stick.

---

## What This Covers

When you're setting up a network, one of the first things you need to figure out is **how to physically connect your devices** 
 and which cable to use. Get this wrong and data just won't flow, no matter how well everything else is configured.

This repo breaks down:

- The three cable types you'll use most often
- Which cable goes between which devices (and *why*)
- How distance determines your fiber choice

---

## Quick Reference: Which Cable for Which Connection?

| Connection Type       | Cable to Use       |
|-----------------------|--------------------|
| PC → Switch           | Straight-through   |
| Server → Switch       | Straight-through   |
| Switch → Switch       | Crossover          |
| Switch → Router       | Straight-through   |
| Router → Router       | Crossover (copper) or Fiber |
| PC → PC (direct)      | Crossover          |
